## Ce que veut l'humain (Ismael, RAILOVER)

Un jeu Roblox jouable et qualitatif nomme BATTLEROT, produit par une equipe de 10 roles d'agents (voir `TEAM.md`,
`agents/<role>/ROLE.md`) qui communiquent par fichiers, tickets et PR, jamais par chat libre. Exigences du jeu, toutes
verifiees point par point dans `docs/reviews/BATTLEROT-audit-prompt-2026-10-01.md` et consolidees dans `design/brief/BATTLEROT.md` :

- auto-battler type TFT + collection de cartes type Clash Royale (raretes, niveaux, puissance = rarete x niveau) ;
- combat au tour par tour type Final Fantasy : Attaque, Competence, Garde, Duo, Mega Combo (animations Blender plus tard) ;
- unites = brainrots mainstream (lot L0, 42 unites) + 1 synergie "Tentafruit" + lots L1/L2 de memes recents trouves par
  API publiques (`tools/trends/`), Six Seven inclus, chaque nouveau lot valide par l'humain (editorial + juridique) ;
- mode Histoire PvE avec oeufs (coffres), mode Versus simple d'abord, ranked plus tard ; recompenses PvP/PvE limitees
  par heure et par jour ; arenes cartoon en Blender ; mobile d'abord ; ouverture d'oeuf energique sans copier les assets CR.

Preferences de communication : francais courant, peu de jargon, commandes a copier-coller, reponses courtes et sinceres.
Pas de tiret cadratin dans les docs. Ne jamais declarer le jeu "fun" ou "jouable dans Studio" sans observation humaine.

## Etat exact de l'humain au moment de la passation

1. Roblox Studio installe (Windows x86_64).
2. Depot clone sur le Bureau : `$HOME\Desktop\ROBLOX-SUPER-ENGINEER-TEAM`, branche `devin/1790906273-battlerot-brief-m0`.
3. `rojo.exe` 7.7.0 pose dans ce dossier ; `.\rojo.exe plugin install` fait ; `.\rojo.exe serve default.project.json`
   affiche "Rojo server listening, port 34872".
4. Pas encore fait : ouvrir une place Baseplate dans Studio, Plugins > Rojo > Connect, verifier
   `ReplicatedStorage.Shared.Config` et `ServerScriptService.Server`, Save to Roblox As "BATTLEROT" (prive), Play.

## Prochaine etape pour l'agent qui reprend

1. Aider l'humain a faire le point 4 ci-dessus, puis derouler `tickets/backlog/T-0031-human-playtest-m1-studio.md`
   (32 etapes, resultats chiffres attendus) en lisant la fenetre Output de Studio.
2. Si le MCP Roblox Studio est disponible (menu Assistant de Studio), suivre `docs/mcp-studio.md` et
   `.devin/skills/roblox-studio-mcp/` : lire la console, lancer le play, executer du Luau de verification.
3. Toute erreur rouge : la coller telle quelle dans la section Resultats de T-0031 avec le fichier et la ligne.
   Corriger sur une branche `<role>/T-00xx-<slug>`, gates `python3 tools/check_repo.py`, `tools/lint.sh`,
   `lune run tests/run.luau`, puis PR vers `devin/1790906273-battlerot-brief-m0` (pas vers main).
4. Quand T-0031 est coche sans ecart bloquant : deplacer le ticket dans `tickets/review/`, et seulement ensuite
   ouvrir M2 (vertical slice) via le Producteur (`agents/01-producteur/PLAYBOOK.md`, `PROCESS.md`).
