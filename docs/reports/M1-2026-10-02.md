## 2. Ce qui n'est PAS verifie

- Aucun agent n'a ouvert Roblox Studio : le duel n'a jamais ete joue par un humain ni par un client Roblox. Le code
  serveur qui touche `Players`, `RemoteEvent` et `task.wait` (`DuelService`, `DuelMatch`, `DuelBot`) est analyse par
  luau-lsp et selene seulement.
- Tailles tactiles 44 px et safe area : garanties par construction, non mesurees sur appareil.
- Duree reelle d'un combat anime : 24,5 s sous Lune, a chronometrer dans Studio (T-0031 B6).
- Determinisme du RNG : verifie sous Lune, a confirmer dans Studio (meme seed, meme journal).
- Equilibrage : mesure sur equipes aleatoires, pas sur des equipes de joueurs ; 3 unites L0 au-dessus de 60 %
  (T-0029) ; 8,9 % de nuls en M1 contre une cible de 2 % (T-0028).
- Le jeu n'est pas declare "fun" : seul un playtest humain (T-0031) peut le dire.
